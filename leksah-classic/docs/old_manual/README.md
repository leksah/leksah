# Archived documentation

Everything in this directory describes the old GTK+ (gtk2hs /
GtkSourceView) version of Leksah — the Sphinx manual (`*.rst`, frozen
around version 0.8), its screenshots, and the even older LyX manual. It is
kept for reference only; none of it matches the current reflex-dom web UI.

For current documentation see [docs/getting-started.md](../getting-started.md),
[docs/features.md](../features.md) and [docs/building.md](../building.md).
