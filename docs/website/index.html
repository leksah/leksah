Batteries included

Leksah is deepest at Haskell — and its editor, terminals, git and language-server support work the same for any language.

Your choice of editor

CodeMirror 6 by default, or Monaco — the editor from VS Code — via a preference. Shared find bar, dirty-change gutter, in-editor diffs.

Language servers, zero config

Deep haskell-language-server integration, and automatic use of typescript-language-server, rust-analyzer, gopls, pyright, clangd and nixd when they're on your PATH: diagnostics, hover, completion, go-to-definition, references.

Real terminals

Terminal panes are tmux sessions — persistent, searchable, and still running after a restart. File references in output are clickable.

Git built in

A live changes pane and a history browser with side-by-side diffs for any commit.

Haskell projects, understood

Cabal workspaces, packages and components; incremental and background builds; errors as squiggles and a structured Errors pane; GHCi debugging; cached Nix dev-shell environments.

Remote projects experimental

Open a project over SSH: editing, builds and the language server run on the remote machine while the UI stays local.

AI assistant experimental

Run your AI tool in a terminal pane and send it the current selection, a file#L10-20 reference, the current error, or a screenshot region — straight from the menu.

Multiple windows

Open extra OS windows onto the same session; a tab flipper switches between recent tabs across all of them.

One codebase, every platform

The whole UI is a single reflex-dom program. Each platform just gives it a different home:

macOS — native WKWebView app Linux — GTK4 + WebKitGTK app Windows — Edge WebView2 app Any browser — served over HTTP No install at all — compiled to JavaScript (the demo)

Get it

Install Nix, then:

$ git clone --recursive https://github.com/leksah/leksah.git
$ cd leksah
$ ./leksah.sh --nix ghc914   # native app (or --warp for the browser UI)

See getting started and building from source for details, front-end variants and packaging outputs.

Written in Haskell, since 2007

Leksah isn't just for Haskell — it's one of the larger open-source applications written in it. The UI is functional-reactive programming end to end: the same Haskell renders through a native WebView via jsaddle, over a websocket to your browser, or compiled to JavaScript outright — the demo above is the IDE itself, built with GHC's JS backend.

It's also self-hosting in the most literal sense: Leksah is developed in Leksah, and a running instance rebuilds itself, in place, with its own build system. If you want to see what a substantial, long-lived Haskell codebase looks like — or hack on one — the source is right here.
