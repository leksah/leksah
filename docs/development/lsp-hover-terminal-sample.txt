Test fixture for terminal LSP hover tooltips.

`cat` this in a leksah terminal to reproduce a Claude Code `Update(...)` block,
then mouse over the identifiers on the diff CODE lines below each
`Update(...)` header (not just the header itself) — e.g. `unsafePerformIO`,
`lookupEnv`, `readMaybe`, `leksahPort`, `defaultLeksahPort`, `instanceTag`,
`tmuxServerSocket` — and confirm the LSP tooltip appears.

The block references the real file src/IDE/Web/Instance.hs at its real line
numbers, so the gutter line number + column of each hovered identifier maps to
a genuine position HLS can resolve.  (The `+` lines are hypothetical edits and
won't line up with the current file; the unchanged context lines and the `-`
lines do.)
